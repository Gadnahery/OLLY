# OLLY — Food-Processing Business ERP

ERP-level intelligence. The user never feels like they are using an ERP.

## Stack
React 19 + Vite + Tailwind 4 + Supabase

## Setup
npm install
npm run dev

## Deploy
Connect GitHub repo to Vercel. Set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY.

Migrations already applied to project hjvuyzjgkddkqjnilmtf.
